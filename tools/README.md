# tools/

Interne Hilfswerkzeuge (nicht Teil des Scope-Produkts, nicht öffentlich deployed).

## lead-radar.html

Ein eigenständiges Dashboard zur Akquise: vorgefilterte Suchen nach **Website-Bau-Anfragen im 20-km-Umkreis um Moers** (Kleinanzeigen, Freelance-Börsen, Facebook, Google Maps).

**Nutzung:** Datei per Doppelklick im Browser öffnen. Karte anklicken → die gefilterte Suche öffnet sich in einem neuen Tab. Auf Kleinanzeigen zusätzlich links **„Nur Gesuche"** aktivieren, um Anbieter/Konkurrenz auszublenden.

Der Umkreis steckt im Link-Code `l2126r20` (Moers + 20 km); für einen engeren Radius `r20` → `r10` ändern.
